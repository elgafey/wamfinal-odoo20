# Account Search Without Parent (account_search_no_parent) — وحدة Odoo 20

**الإصدار:** `20.0.1.0.0`
**الاعتماديات:** `account`
**الرخصة:** LGPL-3

وحدة صغيرة واحدة غايتها واحدة: **عند البحث عن حساب في أي شاشة، يظهر الحساب نفسه فقط — من غير أسماء الحسابات الآباء.**

---

## 1. المشكلة

Odoo 20 أضاف تدرجًا **حقيقيًا** على دليل الحسابات (حقل `parent_id` على
`account.account`). وفي قوائم اختيار الحسابات (dropdowns) النواة تعرض
`name_path` — وهو **سلسلة أسماء الآباء كاملة + اسم الحساب**:

```
160101 Cash at Bank / Main SAR Operating Account
```

فالمستخدم يبحث عن حسابه فيجد اسم الأب مكدسًا قبله في كل الشاشات.

## 2. الحل

الوحدة تعيد تعريف `_compute_display_name` لـ `account.account`: في سياق
الـ dropdown (`formatted_display_name`) تعرض **الكود + اسم الحساب نفسه فقط**:

```
160101 Main SAR Operating Account
```

* **الكود يظل ظاهرًا** لمستخدمي المحاسبة (`account.group_account_readonly`) —
  هو هوية الحساب وطريقة البحث الطبيعية للمحاسبين.
* **خارج الـ dropdown** سلوك النواة لم يتغير حرفيًا (كود + اسم).
* **البحث بالمحتوى لم يتغير:** البحث باسم الأب ما زال يجد الأبناء — الوحدة
  نظّفت **العرض** فقط ولم تغير دلالات البحث (مقصود: البحث بالأب لإيجاد
  الأبناء عادة مشروعة ومفيدة).
* ملاحظة وصف الحساب (`description`) الذي كانت النواة تعرضه سطرًا ثانيًا في
  الـ dropdown لم يعد يظهر — الطلب كان عرضًا نظيفًا.

## 3. أمان الإزالة

الوحدة **لا تضيف أي حقل أو عمود أو جدول** — تعريف واحد لدالة عرض واحدة.
إزالتها ترجع العرض لسلوك النواة فورًا بلا أي أثر في قاعدة البيانات.

## 4. التثبيت والاختبار

```bash
# تثبيت
odoo -d YOUR_DB -i account_search_no_parent --stop-after-init

# الاختبارات (5 اختبارات)
odoo -d YOUR_DB -u account_search_no_parent \
     --test-enable --test-tags /account_search_no_parent \
     --stop-after-init --no-http
```
